# ProjectCam

برنامه‌ای اندرویدی برای مستندسازی مصور مراحل انجام پروژه‌های عمرانی. برای هر عکس به‌صورت خودکار **نام پروژه**، **مختصات جغرافیایی (GPS)**، **نام عکاس** و **تاریخ و ساعت شمسی** روی خود تصویر درج می‌شود، و در پایان می‌توانید از عکس‌های هر پروژه یک خروجی **KML + عکس‌ها** در قالب یک فایل **ZIP** بگیرید تا در Google Earth مشاهده کنید.

## ویژگی‌ها

- ✅ ایجاد چند پروژه عمرانی، هرکدام با مجموعه عکس‌های مستقل
- ✅ ثبت عکس با دوربین داخل برنامه (CameraX) و درج خودکار واترمارک:
  - نام پروژه
  - نام عکاس (یک‌بار در تنظیمات وارد می‌شود)
  - مختصات GPS به همراه دقت (± متر)
  - تاریخ و ساعت شمسی
- ✅ نشانگر زنده وضعیت و دقت GPS هنگام گرفتن عکس، با امکان تلاش دوباره اگر سیگنال ضعیف بود
- ✅ گرید عکس‌های هر پروژه با امکان انتخاب چندتایی (نگه‌داشتن انگشت روی عکس)
- ✅ خروجی KML + ZIP: هم برای عکس‌های انتخاب‌شده، هم برای کل عکس‌های یک پروژه؛ هر عکس در Google Earth با پین و توضیحات (عکاس/تاریخ/یادداشت) نمایش داده می‌شود
- ✅ پشتیبان‌گیری کامل (Export/Import دستی) در کنار Auto Backup اندروید
- ✅ کاملاً راست‌به‌چپ (RTL) با فونت Vazirmatn و تقویم شمسی

## نکات فنی مهم

- **تاریخ شمسی**: الگوریتم تبدیل قبل از پیاده‌سازی در Kotlin، در پایتون نوشته و در برابر کتابخانه مرجع `jdatetime` روی بازه‌ی ۱۹۲۰ تا ۲۱۰۰ (بیش از ۶۶ هزار روز پشت‌سرهم) با round-trip کامل تست شد. همیشه از `java.time.LocalDate` استفاده می‌شود، نه `java.util.Calendar` (که در برخی گوشی‌های ایرانی رفتار locale-dependent اشتباه دارد).
- **مسیر فایل عکس‌ها**: در دیتابیس فقط **نام فایل** ذخیره می‌شود، نه مسیر کامل؛ چون مسیر مطلق بین نصب‌های مختلف (بازیابی پشتیبان، تعویض گوشی) تغییر می‌کند. مسیر واقعی همیشه هنگام نیاز از طریق `PhotoFileUtils` بازسازی می‌شود.
- **ذخیره‌سازی**: عکس‌ها در حافظه اختصاصی برنامه (`Android/data/ir.k1adili.projectcam/files/Pictures/ProjectCam`) نگه‌داری می‌شوند؛ نیازی به دسترسی ذخیره‌سازی در اندروید ۱۰ به بعد نیست.
- **خروجی KML**: فایل zip شامل `doc.kml` در ریشه و پوشه `files/` با تصاویر است (ساختار مشابه KMZ)؛ هر Placemark شامل مختصات + توضیحات با عکس thumbnail است.
- **پشتیبان‌گیری**: دو لایه دارد — Auto Backup اندروید (خودکار، محدودیت حجم دارد) و Export/Import دستی از تنظیمات (فایل ZIP شامل manifest.json + همه عکس‌ها، بدون محدودیت حجم OS).

## بیلد کردن

```bash
./gradlew assembleDebug
```

APK خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

### بیلد خودکار با GitHub Actions

هر push روی شاخه `main` باعث اجرای تست‌ها و ساخت یک APK دیباگ می‌شود (در تب Actions ریپو قابل دانلود است).

برای ساخت نسخه Release امضاشده، یک تگ نسخه پوش کنید:

```bash
git tag v1.0.0
git push origin v1.0.0
```

اگر می‌خواهید APK امضا شود، این Secret ها را در تنظیمات ریپو (Settings → Secrets and variables → Actions) اضافه کنید:

| Secret | توضیح |
|---|---|
| `KEYSTORE_BASE64` | خروجی `base64 -w0 release.keystore` |
| `KEYSTORE_PASSWORD` | رمز کیستور |
| `KEY_ALIAS` | نام alias کلید |
| `KEY_PASSWORD` | رمز کلید |

بدون این Secret ها، APK بدون امضا ساخته می‌شود (قابل نصب مستقیم روی گوشی خودتان، اما برای انتشار در استورها باید امضا شود).
